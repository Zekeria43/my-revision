🚀 Run the full app

# from the project folder (marevision/)
npm install
npx prisma migrate dev
npm run db:seed
npm run dev            # → http://localhost:3000
npm run build && npm start   # production → :3001

Public hosting: the full app is a Next.js server (auth + database) — deploy it to Vercel or any Node host. This Surge page is a static landing only.
